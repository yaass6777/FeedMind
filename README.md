# FeedMind

Intelligent Personalized Content Aggregation and Recommendation Platform.

## Project Overview

FeedMind aggregates articles from curated RSS feeds and provides users with a unified, personalized content feed.

## Technology Stack

- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Python, FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy 2.x
- Migrations: Alembic
- Recommendation Engine: TF-IDF and Cosine Similarity
- Containerization: Docker and Docker Compose

## Architecture

Modular Monolith with a Separate RSS Background Worker.
